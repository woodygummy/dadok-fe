# 다독 (dadok-fe)

읽은 시간과 쪽 수를 가볍게 남기는 프론트엔드 초안입니다. 지금은 백엔드 없이 브라우저 `localStorage`에만 저장됩니다.

개발 브랜치는 `dev`입니다. `main`에는 아직 올리지 않았습니다.

## 실행

```bash
npm install
npm run dev
```

기본 주소는 [http://127.0.0.1:43147](http://127.0.0.1:43147) 입니다.

## 이 초안에 있는 것

- 오늘 대시보드: 읽는 중, 오늘 시간/쪽, 최근 기록
- 서재: 상태 탭, 검색, 책 추가
- 책 상세: 진도, 읽기 기록, 상태 변경

예시 책 네 권이 처음 한 번 들어갑니다. 서재에서 비우거나 예시를 다시 넣을 수 있습니다.
